URL workspace

Humans and agents share the same query string: ?q, ?date (today / tomorrow / week / upcoming), ?category, ?topic, ?source, ?event. Read valid topic slugs from events.json.topic_vocabulary.topics.

Browser WebMCP tools include get_ui_state, apply_ui_state, and build_calevents_url.

CRUD limits

Events and feed status are read-only. There is no create, update, or delete for campus events through CalEvents. Calendar export and directions URLs are derived reads.
